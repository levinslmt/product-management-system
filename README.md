# Product Management System

A simple Product Management System built as a technical exam project.

## Features

- User registration and login
- JWT authentication
- Product CRUD
  - Create
  - Retrieve
  - Update
  - Delete
- Product report
- Protected routes
- SQL Server database

## Technologies

### Frontend
- React
- TypeScript
- Ant Design
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MSSQL
- JWT
- bcrypt
